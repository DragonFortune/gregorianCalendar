# Calendar

Тестовое задание.
Программа генерирует календарь на любой год с
учетом григорианского календаря, выводит его в консоль и поддерживает экспорт
в txt и csv.

> Сколько всего уникальных календарей существует вне зависимости от номера года?
>
> - Существует 14 уникальных календарей (7 возможных дней начала года * 2 типа года (обычный / високосный))

# Немнего о программе

Для вычисления первого дня года используется **формула Зеллера**:
> **h = ( q + ⌊13 × (m + 1) / 5⌋ + K + ⌊K / 4⌋ + ⌊J / 4⌋ + 5 × J ) % 7**

где:
- **h** — день недели
- **q** — день месяца
- **m** — месяц
- **K** — год века (`year % 100`)
- **J** — век (`year / 100`, целая часть)
